# 04 — Mise en œuvre

Cette partie accueillera les procédures et configurations réellement utilisées pendant le déploiement.

Organisation envisagée :
- network : VLAN, adressage, routage et filtrage réseau ;
- twingate : Connector, ressources et règles d'accès ;
- active-directory : AD DS, DNS, groupes et comptes ;
- servers : serveur de fichiers et intranet ;
- host-firewalls : règles Windows Defender Firewall et nftables.

Les sous-dossiers seront créés lorsqu'ils contiendront des éléments concrets. Les configurations publiées seront expurgées de tout secret.

Distinguer les configurations prévues, appliquées et effectivement vérifiées.
